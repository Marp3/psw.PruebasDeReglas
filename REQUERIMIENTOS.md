# OBJ -> Objectivo
Este sistema existe para administrar pequeños emprebdimientos y tienas, su exito y porposito radica en ser un apoyo y gestor adecuado dentro de cualqueir tiendita de la esquina

## CU -> Casos de Uso
* CU-001 -> Se ingresan los porductos
* CU-002 -> Se maneja la tienda

## RN -> Regla de negocio
* RN-001 -> Hacer retiro cada 1500 pesos en ventas. Iniciar en 500 pesos
* RN-002 -> Si un empleado tiene mas de 3 faltas al mes sin justificación despido.
* RN-003 -> Se maneja un inventario general de los productos dentro del sistema.

## AC -> Criterio de aceptación
* AC-001 -> Si la caja llego a 1500 en ventas se le notificara al usuario que se suspenderá el cobro de transacciones.
* AC-001 -> El sistema notifica al encargado cuando un empleado tiene una falta y a la tercera falta se le registra como despido.
* AC-001 -> Se hace un seguimiento semanal del inventario y se norifican faltantes, porductos para resurtir y productos con pocas ventas.
