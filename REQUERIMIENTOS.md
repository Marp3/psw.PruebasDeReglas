# RN
Regla de negocio
Hacer corte cada 1500 pesos en ventas
Si un empleado tiene mas de 3 faltas sin justificación despido

# AC
Criterio de aceptación
Si la caja llego a 1500 en ventas se le notificara al usuario que se suspenderá el cobro de transacciones
El sistema notifica al encargado cuando un empleado tiene una falta y a la tercera falta se le registra como despido
