# OBJ
Este sistema existe para administrar pequeños emprebdimientos y tienas, su exito y porposito radica en ser un apoyo y gestor adecuado dentro de cualqueir tiendita de la esquina

# CU
-/CUN001/-Se ingresan los porductos
-/CUN002/-SE maneja la tienda

# RN
Regla de negocio
-/RN001/-Hacer corte cada 1500 pesos en ventas.
-/RN002/-Si un empleado tiene mas de 3 faltas sin justificación despido.
-/RN003/-Se maneja un inventario general de los productos dentro del sistema.

# AC
Criterio de aceptación
-/ACN001/-Si la caja llego a 1500 en ventas se le notificara al usuario que se suspenderá el cobro de transacciones.
-/ACN001/-El sistema notifica al encargado cuando un empleado tiene una falta y a la tercera falta se le registra como despido.
-/ACN001/-Se hace un seguimiento semanal del inventario y se norifican faltantes, porductos para resurtir y productos con pocas ventas.
